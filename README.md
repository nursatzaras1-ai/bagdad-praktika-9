# Практикалық жұмыс №9 — Бисенов Бағдад

GitHub Pages үшін дайын сайт. index.html және assets бумасын репозиторийдің негізгі бетіне жүктеңіз.

1. GitHub-та жаңа public репозиторий ашыңыз: bagdad-praktika-9.
2. ZIP архивін ашып, ішіндегі index.html, assets бумасын және .nojekyll файлын репозиторийге жүктеңіз. ZIP файлының өзін жүктемеңіз.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch.
4. Branch: main; Folder: / (root); Save.
5. Жариялау аяқталған соң сілтеме Settings → Pages бөлімінде көрсетіледі.

Құжаттағы мәтін мен 12 сурет сақталған. Суреттер assets бумасында болуы керек.
